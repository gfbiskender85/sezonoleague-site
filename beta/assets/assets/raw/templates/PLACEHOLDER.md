# Logo Templates Klasörü

22 template = kulüp logoları için iskelet. Backend `LogoCompositionService`
runtime'da renk + center element overlay yaparak ~3.000 kulübün logosunu üretir.

## Beklenen 22 dosya

`01_square.png` ... `22_pentagon.png` (../README.md tam liste)

## Üretim Kuralları

- Format: PNG transparent background
- Boyut: 1024×1024
- Renk: PURE BLACK AND WHITE
- --sref tutarlılığı: master logo ile aynı code
